# Acuerdo de Licencia de Contribuidor (CLA) de Lámina

Al enviar una contribución (código, documentación, componentes, traducciones) a este repositorio, aceptas lo siguiente:

1. **Titularidad.** Conservas los derechos de autor de tu contribución. Declaras que es tuya (o que tienes derecho a aportarla) y que no incluye código bajo condiciones incompatibles con la AGPL-3.0.
2. **Licencia a Cúpula Systems.** Otorgas a Cúpula Systems y a quienes reciben el software una licencia perpetua, mundial, no exclusiva, gratuita e irrevocable para usar, reproducir, modificar, sublicenciar y distribuir tu contribución como parte de Lámina, bajo la **AGPL-3.0** y, si Cúpula Systems lo decidiera para ofrecer el servicio o versiones institucionales, bajo otras licencias, incluidas las comerciales.
3. **Patentes.** Otorgas una licencia de patentes equivalente sobre las reivindicaciones que tu contribución necesariamente infrinja.
4. **Sin garantía.** Tu contribución se ofrece «tal cual». No estás obligado/a a dar soporte.
5. **Componentes generados por IA.** Si tu contribución incluye código producido con ayuda de IA, declaras haberlo revisado y que puedes licenciarlo en estos términos.

La aceptación se registra automáticamente en cada pull request mediante [CLA Assistant](https://github.com/cla-assistant/cla-assistant) (el bot pedirá firmar una sola vez con tu cuenta de GitHub).
